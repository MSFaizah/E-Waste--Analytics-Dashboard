## 🌍 E-Waste Analytics Dashboard
## 📌 Introduction
The **E-Waste Analytics Dashboard** is a Power BI-based data visualization system designed to analyze electronic waste collection across multiple dimensions such as **location, class, and time**. It transforms raw data into **actionable insights** using statistical techniques like **Pareto Analysis, Efficiency Metrics, and Distribution Analysis**.

## 🎯 Project Objectives
| Objective             | Description                                  |
| --------------------- | -------------------------------------------- |
| Impact Tracking       | Measure total e-waste collected across years |
| Contribution Analysis | Identify top-performing classes & locations  |
| Efficiency Evaluation | Analyze kg collected per individual          |
| Growth Monitoring     | Track year-on-year trends                    |
| Strategic Insights    | Optimize future collection drives            |

## 🧩 Dashboard Components
| Section                    | Visuals Used            | Key Insight                     |
| -------------------------- | ----------------------- | ------------------------------- |
| Impact Overview            | KPI Cards, Line Chart   | Total collection & growth trend |
| Class-Wise Contribution    | Clustered Column Chart  | Top contributing batches        |
| Location Category Analysis | Pie / Donut Chart       | Contribution by type            |
| Top Locations              | Leaderboard / Bar Chart | Highest performing areas        |
| Geographic Distribution    | Map Visual              | Spatial spread of collection    |
| Efficiency Analysis        | Bar + Reference Lines   | Performance per collector       |
| Pareto Analysis            | Bar + Line Combo        | 80/20 contribution rule         |

## 🧠 Analytical Techniques Used
| Technique       | Purpose                           | Outcome                        |
| --------------- | --------------------------------- | ------------------------------ |
| Pareto Analysis | Identify high-impact contributors | Top groups contributed ~86%    |
| Mean vs Median  | Validate distribution consistency | Stable ~24 kg per collector    |
| Trend Analysis  | Track yearly growth               | Increasing awareness over time |
| Data Modeling   | Resolve mapping ambiguity         | Accurate geo-visualization     |

## 📈 Numbered Impact (Key Results)
1. 📦 **2000+ kg** of total e-waste collected
2. 🏆 **Top 4 groups contributed ~86%** of total volume (Pareto Insight)
3. ⚖️ **~24 kg per collector** — consistent performance benchmark
4. 📊 **Year-on-year growth observed** from 2022 to 2025
5. 🗺️ **Multiple high-density collection zones identified**
6. 🎯 **Efficiency metric exposed hidden high performers**
7. 📉 **Low variance indicates balanced participation**
8. 🚀 **Strategy shift identified: Scale participation, not effort**

## 🔍 Key Insights Explained

### 1. Pareto Insight
A small number of contributors drive the majority of impact.
👉 Focus future efforts on **scaling high-performing groups**
### 2. Efficiency Insight
Performance should be judged by **kg per person**, not total kg
👉 Ensures fair comparison across groups
### 3. Mean vs Median Insight
* Mean ≈ Median (~24 kg)
* Indicates **consistent participation, not outliers**
👉 This proves the system is **scalable and predictable**

### 4. Strategy Insight
Success was driven by:
* High participation volume
* Consistent individual contribution
👉 Future strategy = **increase participation count**
